# Corrections and takedown

If a tracker or rules entry is wrong, or you are named in a decision and want an entry reviewed, please open an issue on this repository or use the contact form linked on the site. [CONTACT METHOD TO BE SET BY LUC BEFORE RELEASE]

What we will do:
- Check the request against the judgment or instrument within 7 days.
- Correct errors, and log every change in CHANGELOG.md.
- Where an entry concerns a self-represented person, we will consider removing identifying detail even if the entry is accurate. The tracker only records what the court published.
